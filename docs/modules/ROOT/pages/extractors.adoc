= Extractors in Mapping Suite SDK
:description: Advanced usage and customization of package extractors
:keywords: mapping-suite-sdk, extractors, github, archive, custom extractors

== Overview

The Mapping Suite SDK provides two primary extractors for handling mapping packages:

- `ArchiveExtractor`: For working with ZIP archives
- `GitHubExtractor`: For extracting packages from GitHub repositories

Import from `mapping_suite_sdk.core.adapters.extractor`.

== Archive Extractor

=== Basic Usage

[source,python]
----
from pathlib import Path
from mapping_suite_sdk.core.adapters.extractor import ArchiveExtractor

extractor = ArchiveExtractor()
output_path = extractor.extract(Path("package.zip"), Path("output_directory"))

with extractor.extract_temporary(Path("package.zip")) as temp_path:
    print(f"Extracted to temporary path: {temp_path}")
----

=== Packing a directory

[source,python]
----
source_dir = Path("folder_to_archive")
output_path = Path("output/my_package")
zip_path = extractor.pack_directory(source_dir, output_path)
----

== GitHub Extractor

=== Single package

[source,python]
----
from pathlib import Path
from mapping_suite_sdk.core.adapters.extractor import GitHubExtractor

extractor = GitHubExtractor()
package_path = extractor.extract(
    repository_url="https://github.com/org/repo",
    destination_path=Path("/local/path"),
    package_path=Path("mappings/package_v1"),
    branch_or_tag_name="main",
)
----

=== Multiple packages (pattern)

[source,python]
----
with extractor.extract_temporary(
    repository_url="https://github.com/org/repo",
    packages_path_pattern="mappings/package*",
    branch_or_tag_name="v1.0.0",
) as package_paths:
    for path in package_paths:
        print(f"Found package at: {path}")
----

=== Git-based behaviour

The GitHub extractor uses *Git* to clone the repository (shallow clone, depth=1) and then resolves package paths from the working tree. The same mechanism is used when you load or validate packages from GitHub without using the extractor directly:

* *Loading from GitHub* — Version-specific loaders clone the repo and load each matching package: `load_mapping_packages_v1_from_github`, `load_mapping_packages_v2_from_github`, `load_mapping_packages_v3_from_github`, `load_mapping_packages_v3_lightweight_from_github` (in the corresponding `mapping_package_v1`, `mapping_package_v2`, `mapping_package_v3` services). They accept `github_repository_url`, `packages_path_pattern`, and `branch_or_tag_name`.
* *Validating from GitHub* — The CLI command `mssdk validate from-github GITHUB_REPOSITORY_URL PACKAGES_PATH_PATTERN` clones the repository and validates each matching package. Use `--branch` to specify branch or tag.

So you can either use `GitHubExtractor` for low-level clone and path discovery, or the version-specific loaders and the validate CLI, which use the extractor under the hood.

== Custom Extractor

Implement `ExtractorABC` from `mapping_suite_sdk.core.adapters.extractor`:

[source,python]
----
from mapping_suite_sdk.core.adapters.extractor import ExtractorABC

class CustomPackageExtractor(ExtractorABC):
    def extract(self, *args, **kwargs):
        # Your logic
        pass

    def extract_temporary(self, *args, **kwargs):
        # Your logic; yield path(s)
        pass
----

== Best Practices

- Always use context managers (`with` statement) for temporary extractions
- Handle exceptions gracefully
- Be mindful of system resources when working with large packages
- Consider network and storage limitations when extracting from remote sources

== Error Handling

[source,python]
----
from pathlib import Path
from mapping_suite_sdk.core.adapters.extractor import ArchiveExtractor, GitHubExtractor

def safe_extract(extractor, source):
    try:
        with extractor.extract_temporary(source):
            # Process extracted paths
            pass
    except FileNotFoundError:
        print(f"Source not found: {source}")
    except ValueError as e:
        print(f"Extraction error: {e}")

# Example usage
archive_extractor = ArchiveExtractor()
github_extractor = GitHubExtractor()

safe_extract(archive_extractor, Path("non_existent.zip"))
safe_extract(
    github_extractor,
    "https://github.com/non-existent-repo/mapping-packages"
)
----
