= Mapping Package Validation

The Mapping Suite SDK provides validation to ensure the integrity and correctness of mapping packages (structure, hash signature). You can validate via the CLI (see xref:cli.adoc[CLI]) or programmatically.

== Programmatic Validation

Use `validate_mapping_package` from `mapping_suite_sdk.tools.services.validate_mapping_package`. It accepts either a path (folder or archive) or an in-memory package model; version can be auto-detected or passed explicitly.

=== Validate by path (folder or archive)

[source,python]
----
from pathlib import Path
from mapping_suite_sdk.tools.services.validate_mapping_package import validate_mapping_package

# Folder: version auto-detected or explicit
validate_mapping_package(Path("/path/to/mapping/package"))
validate_mapping_package(Path("/path/to/package"), version="v2")

# Archive: version is detected after extraction
validate_mapping_package(Path("/path/to/mapping-package.zip"))
----

=== Validate an in-memory package

[source,python]
----
from mapping_suite_sdk.tools.services.validate_mapping_package import validate_mapping_package
from mapping_suite_sdk.mapping_package_v2.services.load_mapping_package_v2 import (
    load_mapping_package_v2_from_folder,
)
from pathlib import Path

package = load_mapping_package_v2_from_folder(mapping_package_folder_path=Path("/path/to/package"))
validate_mapping_package(package)
----

== Version-specific validation

Each version also exposes its own validators (e.g. `validate_mapping_package_v2_from_folder`, `validate_mapping_package_v2_from_archive`) in the corresponding `mapping_package_v1`, `mapping_package_v2`, `mapping_package_v3` services.

== Error Handling

On failure, validation raises exceptions such as `MPHashValidationException` or `MPStructuralValidationException`. Catch these to handle errors in your application.
